Progetti

Impara le bandiere con c#

Il progetto consiste in due giochi. Il primo gioco, interamente sviluppato da me consiste nel classico gioco del memory, dove bisogna accoppiare due bandiere uguali tra tutte le bandiere del mondo. In base alla difficolta e ai tentativi totali verrà assegnato un punteggio che sarà accompagnato da un nome giocatore che saranno inseriti in una file classifica.txt. Il secondo gioco sviluppato da i miei compagni Nesfintu Stefania e Pagliuca Gabriel consiste in indovinare il paese di una bandiera.

Tris in Java utilizzando Swing GUI

Questo capolavoro consiste nel semplice gioco del Tris, riproposto in una chiave più tecnologica, tramite l'utilizzo del linguaggio di programmazione Java e la libreria grafica Swing. All'interno si trovano due modalità uno scontro tra due giocatori, oppure una partira contro un Bot di 3 difficoltà diverse (Facile, Medio, Difficile). Inoltre è implementata documentazione tramite JavaDoc.
